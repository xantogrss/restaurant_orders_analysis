### Крок 5. Результати бенчмарку та аналіз складності

Таблиця аналізу складності операцій:

| Операція                           | Часова складність |
| ---------------------------------- | ----------------- |
| Пошук елемента в list              | O(n)              |
| Пошук за ключем у dict             | O(1)              |
| Перевірка наявності елемента в set | O(1)              |
| Сортування sorted()                | O(n log n)        |

Експериментальна таблиця:

| Кількість записів |    List Search |    Dict Search |
| ----------------- | -------------: | -------------: |
| 1 000             | 0.00005120 сек | 0.00000080 сек |
| 10 000            | 0.00054310 сек | 0.00000090 сек |
| 100 000           | 0.00621040 сек | 0.00000110 сек |

Висновок для звіту: зі збільшенням кількості даних час пошуку у списку зростає лінійно відповідно до складності O(n). Натомість пошук за ключем у словнику залишається майже сталим і має середню складність O(1) завдяки хешуванню. Це показує доцільність використання словників та індексування для роботи з великими обсягами даних.
